## 🔧 Troubleshooting

### Issue: "404 Not Found"

**Solution:** Wait 2-3 minutes, then refresh. First deployment takes time.

### Issue: "Page not found" after 5 minutes

**Solution:**

1. Check you selected `/docs` folder (not `/root`)
2. Ensure branch is `main` (not `master`)
3. Force rebuild: Make a small change and push again

### Issue: "Blank page"

**Solution:**

1. Check browser console for errors
2. Verify `index.html` is in `/docs` folder
3. Clear browser cache and retry
